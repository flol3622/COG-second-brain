# Contributing

Thanks for improving COG. This project is intentionally small and Markdown-first. Please keep contributions aligned to Codex CLI usage.

## Ground Rules
- Keep skills minimal and transparent—no hidden prompts.
- Prefer template edits over ad-hoc formatting so outputs stay consistent.
- Do not add dependencies beyond Codex CLI and Markdown files.

## Workflow
1. Fork and branch from `work`.
2. Make changes with clear commits.
3. Include examples or updated templates when adjusting skills.
4. Open a PR describing the user-facing impact.

## What to Improve
- Skill clarity in `.codex/skills/*/SKILL.md`.
- Templates in `06-templates/`.
- Docs that help users run Codex CLI effectively.
